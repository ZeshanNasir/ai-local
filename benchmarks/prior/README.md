# Prior measurements (not reproduced here)

`ai-bench-prior.csv` holds results logged by an earlier personal shell script (`ai-bench`) on the same machine: one request per model with a short code-generation prompt, thinking at the model default, no repeats, no memory sampling. Only rows with a consistent format are included.

Treat these as context, not evidence: single runs, a different prompt, and conditions that were not recorded. Compare them with `benchmarks/results/`, which are the measurements this project produced and can reproduce.
